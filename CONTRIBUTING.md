# Contributing

Hey, thanks for your interest in contributing to Project Stairway! This monorepo contains everything behind our studio's community and production tooling.


## Code of Conduct

By participating, you agree to follow our [Code of Conduct](https://dev-app.seraphinteractive.com/legal/acceptable-use). Be kind, assume good faith, and keep discussion focused on the work.

## AI Usage Policy

AI tools (Claude Code, Copilot, Cursor, ChatGPT, and similar) are allowed in this project, under the following rules. These rules are mandatory and non-negotiable.

### 1. You must review ALL AI-generated code.

Every line of code AI-generated or modified by AI must be read and understood by you before it is committed. "The AI wrote it" is not an acceptable explanation for a bug, security issue or design choice. If you're unable to explain a change in a review, then don't submit it.

### 2. AI must never make a commit in your place

AI agents may edit files in your working tree, but they **must not** run `git commit`, `git push`, `git tag`, `git merge`, `git rebase`, amend commits, or open pull requests on your behalf. Commits made by an agent may be rejected, and you may be permanently barred from contributing.


### 3. You are responsible for the code your agents write

Code produced by an agent you ran is your code. You are accountable for its correctness, security, licensing, and quality, exactly as if you had typed it yourself. That includes making sure it doesn't contain copied code with incompatible licenses, leaked secrets, or fabricated APIs.
